# Qchip TEC v1.0.1

- 修复“检查更新”出现 FORBIDDEN 的会话认证问题。
- 正常采集、记录日志时可检查并下载更新；安装重启前新增明确的确认／取消弹窗。
- PowerShell 默认安装到当前目录下的 `Qchip-TEC`，支持 `-InstallDir` 指定完整安装位置。
- 新安装的配置、配对和本地历史保存在安装目录 `data` 下，默认 CSV 目录为 `log`。旧数据采用显式复制导入，保留原文件。
- 日志自定义时间范围改为日历与时分秒滚轮，支持数字输入并保留毫秒；精简日志页底部文字。

软件与云桥接共用版本号 1.0.1，公共 UI 为 1.4.3。更新只替换程序文件；重启会短暂停止采集，需重新连接设备，不重放温度、PID 或输出参数。
